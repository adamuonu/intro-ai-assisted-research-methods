# Literature materials

| File | Use |
|---|---|
| `search_log_template.csv` | One row per search you run (Day 1, block 3). The first row is an example to replace. |
| `literature_matrix_template.csv` | One row per verified source (Day 1, block 4). |
| `facilitator_source_list_template.csv` | For facilitators: the real, open-access sources chosen for the Day 1 exercises and printed fallback pack. |

**No papers are supplied with the course.** Facilitators choose real, relevant open-access sources before each delivery and check every citation at the source. Participants find and verify their own. Never add a source to the matrix because an AI tool mentioned it: open it, read the passage, and mark the row as verified only when every check passes.

You can open the CSV files in Excel or any spreadsheet program. Keep them as CSV when you save.
